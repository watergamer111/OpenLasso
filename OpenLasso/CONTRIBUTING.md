# Contributing

Thanks for helping with OpenLasso.

- Build with build.bat or CMake (cmake -S . -B build -A x64). Windows 10 or 11, C++17.
- Keep changes focused: one feature or fix per pull request.
- Describe what you tested on Windows (version, administrator or not, service on or off).
- Do not add third-party frameworks; the project uses the Win32 API only.
