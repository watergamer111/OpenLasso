# Changelog

## 1.0
First public release by watergamer111.

- Process priority, affinity, CPU Sets, memory, I/O, efficiency, thread boost, GPU priority and preference per process
- Persistent rules matching name, full path, folder, wildcards and a default rule (*)
- Auto-throttle with configurable duration and CSV report, Memory Trim, Idle power saver, stay-awake, power plans
- CPU cap, CPU guard, blocked processes, instance spreading
- Graph with per-core CPU, disk and network values, smoothness index
- Threads tab, processor-group affinity for systems with more than 64 CPUs
- Tray icon, tray notifications, start with Windows, start minimized
- Windows service applying rules with the window closed
- Profiles, import/export, command line (--version, --status, --list, --apply, --profile)
